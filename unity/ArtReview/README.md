# Kontrola modelu vybavení

RodAndReel-offline-review.webp je skutečný Blender Cycles render nově modelovaného vybavení. Není to screenshot Unity ani důkaz výsledné grafiky hry.

Model ještě není integrován do runtime FishingRig. Procedurální materiály vyžadují samostatné zpracování pro URP. Zbývá ověřit import, souřadnice, měřítko, geometrii, počet draw calls a výkon na cílovém zařízení; model nelze označit za připravený pro mobilní vydání.

Zdrojový Blender skript je v Tools/Art. Model je původní geometrie vytvořená pro tento projekt.
